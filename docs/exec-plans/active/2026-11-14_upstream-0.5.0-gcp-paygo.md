## Objective

Merge upstream `fikrilal/agy-auth` `v0.5.0` Google Cloud Project (`auth_method: "gcp"`, Pay As You Go) support into `MuchoRio/agy-auth` (`v0.4.2` -> `v0.5.0`) while preserving all fork security hardening, Antigravity IDE/Desktop integration, `credential-user-scope` sync, `installation_id`/`.updaterId`, AES-256-GCM vault encryption, `cmd_rotate`, and `OnTokenRefresh` persistence hooks.

## Context

Upstream `fikrilal/agy-auth` released `v0.5.0` with first-class GCP PayGo account support (`project_id`, `region`, `settings.json` sync, dual consumer/GCP OAuth client discovery, `id_token_email` fallback, and scope-aware account IDs). Direct `git merge` collides on 12 files, collides on ADR numbering (`0005`), and interacts with custom `TokenFile.Extra` JSON preservation, `AGY_CLI_SETTINGS_FILE` model override detection, Desktop target switching, and `import --purge`.

## Scope

### In scope

- Core credential/settings/OAuth/registry upgrades (`internal/agy`, `internal/oauth`, `internal/registry`) with `TokenFile.Extra` preservation for all new GCP fields and `UseNumber()` precision safety in `WithGCPOptions`.
- SSOT `SettingsFile()` path unification (`AGY_AUTH_AGY_SETTINGS_FILE` with fallback to `AGY_CLI_SETTINGS_FILE`).
- Optimized 4 MiB OAuth binary scanning with targeted early exit for Consumer and GCP clients.
- Usage & CLI updates (`internal/usage`, `internal/cli`, `internal/harness/contracts`, `harness/fixtures`) preserving Desktop sync, `rotate`, `OnTokenRefresh`, and adding `--target=desktop` guardrails on `--gcp`.
- Documentation, ADR-0007, version sync (`0.5.0`), and unit/integration test coverage (including Windows permission guards and fork regression tests).

### Out of scope

- Modifying `update.go` release endpoints beyond existing fork settings.
- Committing or tagging without explicit user review after Go verification runs.

## Risks

- Loss of unknown JSON fields or field duplication in custom `TokenFile.UnmarshalJSON`/`MarshalJSON` if new struct fields are not excluded from `Extra`.
- Accidental cross-scope reuse of refresh tokens or registry aliases when one Google `sub` holds both `consumer` and `gcp` accounts.
- `settings.json` CLI mutation during `--target desktop` operations.
